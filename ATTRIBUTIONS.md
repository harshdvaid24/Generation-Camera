# ATTRIBUTIONS

Generation Camera's filter engine was **written from scratch** (see `ERA_ANALYSIS.md` §0.4 for the decision record); no third-party filter library code is included. The following open-source projects were *studied* during design and deserve credit:

| Project | License | What we learned from it |
|---------|---------|--------------------------|
| [wasabeef/android-gpuimage](https://github.com/wasabeef/android-gpuimage) | Apache-2.0 | Android GL filter-chain patterns; lookup/vignette filter shader structure |
| [wysaid/android-gpuimage-plus](https://github.com/wysaid/android-gpuimage-plus) | MIT | CameraX + filtered-video architecture (candidate for v2 video capture) |
| [callebdev/Awesome-Filters](https://github.com/callebdev/Awesome-Filters) | MIT | MVVM + CameraX app structure reference |
| [xizhang/camerax-gpuimage](https://github.com/xizhang/camerax-gpuimage) | Apache-2.0 | CameraX frame-feeding glue (we chose the zero-copy OES path instead) |
| [mikljohansson/retroboy](https://github.com/mikljohansson/retroboy) | MIT | Vintage-hardware emulation decomposition ideas |

Runtime dependencies (all permissively licensed): AndroidX (CameraX, Compose, Lifecycle, ExifInterface) — Apache-2.0; Kotlin/kotlinx-coroutines — Apache-2.0; Coil — Apache-2.0.

Asset note: every LUT, overlay texture and frame graphic in `app/src/main/assets/` is **generated by this repository's own script** (`tools/generate_assets.py`) — no third-party LUT packs, textures, or fonts are bundled.
