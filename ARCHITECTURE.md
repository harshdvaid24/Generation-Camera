# ARCHITECTURE.md — Phase 2

## Overview

Single-module Android app (`:app`), Clean/MVVM, offline-first, **all processing on-device**. No backend, no network permission.

```
┌────────────────────────── UI (Jetpack Compose) ──────────────────────────┐
│ CameraScreen: EraDial ─ DegreeRing ─ FrameSwitch ─ Shutter ─ GalleryNav  │
│ GalleryScreen: MediaStore grid, share/export                             │
└──────────────▲────────────────────────────────────────────▲──────────────┘
               │ StateFlow<CameraUiState>                    │ events
┌──────────────┴────────────── CameraViewModel ──────────────┴─────────────┐
│ owns: eraId, degree(0..10), frameOn, lens, flash, captureState           │
└──────────────▲──────────────────────────────────────────────▲────────────┘
               │ EffectParams                                  │ capture()
┌──────────────┴───────────┐                    ┌──────────────┴───────────┐
│        EraEngine         │                    │     CameraController     │
│ Eras.kt (13 EraConfig)   │                    │ CameraX Preview+Capture  │
│ (eraId, degree, frameOn) │                    │ binds lifecycle, flash   │
│   → EffectParams         │                    └──────────────┬───────────┘
└──────────────▲───────────┘                                   │ JPEG bytes
               │ uniforms                                      ▼
┌──────────────┴──────────────── GL layer ─────────────────────────────────┐
│ EraRenderer (GLSurfaceView.Renderer, GLES 3.0)                           │
│  P1 oes_copy:  OES camera tex ──(gate-weave, down-res)──▶ scene FBO      │
│  P2 blur ×2:   scene ──▶ half-res H ──▶ half-res V FBO                   │
│  P3 era.frag:  scene + blur + sampler3D LUT + dust + leak ──▶ target     │
│  P4 frame quad: alpha-blend era frame PNG (if frameOn)                   │
│ StillProcessor: same passes, full-res JPEG in ──▶ FBO ──▶ readPixels     │
│                 ──▶ CPU Canvas frame composite ──▶ MediaStore JPEG       │
└──────────────────────────────────────────────────────────────────────────┘
```

## Components

### EraEngine (`engine/`)
- `Eras.kt` — the 13 `EraConfig`s: every layer parameter at **degree 10** (max), straight from the Era Spec Table (`ERA_ANALYSIS.md` §0.2).
- `EraEngine.kt` — applies the intensity model (§0.3 scaling curves) to produce a flat **`EffectParams`** (pure data, unit-testable, no GL types).
- `EffectParams` maps 1:1 to the `era.frag` uniforms.

### GL layer (`gl/`)
- `EraRenderer.kt` — owns EGL-context-bound resources: programs (compiled once), FBOs (re-allocated on size change), the camera `SurfaceTexture` (OES texture id), 13 LUT 3D textures, overlay/frame 2D textures. `RENDERMODE_WHEN_DIRTY`; `onFrameAvailable → requestRender`. Receives `EffectParams` via a volatile reference set from the UI thread — uniforms read on the GL thread, no locks on the hot path.
- `CubeLutParser.kt` — `.cube` → `FloatArray` (pure Kotlin, unit-testable); `GlUtils.kt` uploads it via `glTexImage3D(GL_TEXTURE_3D, …, GL_RGB, F16)`.
- `Shaders` live in `assets/shaders/` (versioned, readable, hot-swappable in dev).

### Capture path — preview/still parity (critical requirement)
1. CameraX `ImageCapture` (max resolution, JPEG) → decoded `Bitmap` (EXIF-rotated).
2. `glSurfaceView.queueEvent { StillProcessor.process(bitmap, effectParams) }` — runs on the **same GL context with the same programs and the same `EffectParams` snapshot** taken at shutter press, so the saved still is pixel-identical in look to the preview (minus preview-only motion layers: weave/flicker/flutter, which are time-domain and meaningless in a still; their *spatial* signatures — grain, scanlines, dust — are kept).
3. FBOs at full still resolution (capped at 4096² for GPU limits), `glReadPixels` → `Bitmap`.
4. If `frameOn`: frame PNG composited on a CPU `Canvas` scaled to the still (crisper than GPU-pass at preview res).
5. Saved via `MediaStore` to `Pictures/GenerationCamera/` with era/degree in EXIF `UserComment`.

### Asset structure (`app/src/main/assets/`)
```
luts/era_1900s.cube … era_2020s.cube     (17³, generated, deterministic)
shaders/fullscreen.vert, oes_copy.frag, blur.frag, era.frag, frame.vert/.frag
overlays/dust_{0,1,2}.png                 (1024², alpha specks/fibers/scratches)
overlays/leak_{0,1}.png                   (1024², additive warm gradients)
frames/frame_<era>.png                    (1080×1440, alpha-center)
```
All generated by `tools/generate_assets.py` (seeded → reproducible builds).

### State & lifecycle
- Permission gate (CAMERA) in `MainActivity` before composing `CameraScreen`.
- Dial/degree/frame state survive process death via `SavedStateHandle`.
- Renderer resources released in `onPause` (GLSurfaceView contract); camera unbinds with lifecycle.

### Threading
| Thread | Work |
|--------|------|
| Main | Compose UI, ViewModel state |
| GL thread (GLSurfaceView) | All GL: preview passes + still processing |
| CameraX executor | Capture callbacks, JPEG decode |
| `Dispatchers.IO` | MediaStore writes, gallery queries |
